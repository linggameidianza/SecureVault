6 alasan data Anda lebih aman di SecureVault

01

Tidak bisa di-capture

Screenshot & rekam layar diblokir sistem (FLAG_SECURE). Isi aplikasi juga disembunyikan di daftar Recent Apps.

Layar selalu terlindungi
02

Cek kebocoran data

Terintegrasi Have I Been Pwned: cek password, audit semua password tersimpan, dan cek email yang pernah bocor.

Password tak pernah dikirim
03

Pengingat password expire

Atur masa berlaku 30–365 hari. Notifikasi otomatis H-2 sebelum kedaluwarsa, plus penanda oranye/merah di daftar akun.

Dicek tiap 6 jam di latar
04

Enkripsi AES-256

Password & catatan dienkripsi AES-256-GCM dengan kunci di Android Keystore — kunci tidak pernah keluar dari perangkat.

AES-256-GCM · Keystore
05

PIN + biometrik

Buka dengan PIN (hash PBKDF2) atau sidik jari/wajah. Terkunci otomatis 30 detik di latar & lockout bertingkat setelah 5x salah.

Auto-lock 30 detik
06

Backup & restore terenkripsi

Semua akun, catatan & tugas dalam satu file .svbk terkunci password (PBKDF2 210.000 iterasi). Mudah pindah HP.

Gabungkan / ganti semua

Cara kerja cek kebocoran

Password diperiksa tanpa pernah dikirim

SecureVault memakai metode k-Anonymity dari database Pwned Passwords milik Have I Been Pwned. Pencocokan terakhir dilakukan di HP Anda.

1

Password di HP

Password yang ingin diperiksa tetap berada di perangkat.

P@ssw0rd123
2

Hash SHA-1

Diubah menjadi hash 40 karakter yang tidak bisa dibalik.

0F0D9…E7C5F
3

Kirim 5 karakter

Hanya 5 karakter awal hash yang dikirim ke API HIBP.

/range/0F0D9
4

Cocokkan lokal

HIBP membalas ratusan hash serupa; HP mencocokkan sendiri.

cocok? → jumlah bocor
Server HIBP tidak pernah tahu password Anda. Cek email memakai API key HIBP yang disimpan terenkripsi.
